Hello Developers! We are excited to announce the release of **Flamingo Client 1.0.0**! This update fixes most of the bugs spotted during development and integrates the latest features that we couldn't include earlier.

## Update notes

**Fixes**
- Request builder save won't save to collection
- Environment selector not being able to select

**Added**
- Added update checker on startup
- Request params now appear on URL

## What does this update mean

This update is a huge step in Flamingo's trajectory, but also in many developers' lives.

With Flamingo we had only one mission: **Build an API client that developers genuinely enjoy using again.**

With this version, we are accomplishing this goal and marking a before and after for many developers who just want something simpler than other alternatives.

## What changes are coming next

We have planned many upcoming changes for future updates, but without making Flamingo a bloated client with unnecessary features or overcomplicated usage.

We are going to maintain a constant update rhythm with one minor update every 2 weeks or less, and one major update on the last **Friday of every month**.
